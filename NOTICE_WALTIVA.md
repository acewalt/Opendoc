# Waltiva — ONLYOFFICE local engine

This branch is based on `sweetwisdom/onlyoffice-web-local` at commit `c4905016372a633cfba59a78f0acb3f029c85883`.

The upstream project uses OnlyOffice WebSDK together with `x2t-wasm` to open, edit and export Office documents locally in the browser. Waltiva keeps the upstream GNU Affero General Public License v3 (AGPL-3.0) and this source remains publicly available under the same license where required.

Upstream: https://github.com/sweetwisdom/onlyoffice-web-local

Waltiva will customize branding, language, document library, PDF workflow and visual design on top of this engine.
